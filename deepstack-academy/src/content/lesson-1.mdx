# Lesson 1: The Modern UI & Foundation

Welcome to the foundation of web development. We will ensure you do not just memorize tags, but understand how browsers render interfaces. This is the cornerstone of all front-end engineering.

## HTML5 & Accessibility (A11y)

The internet is for everyone. When you write HTML, you are creating a Document Object Model (DOM) tree. This tree is what the browser's rendering engine uses to paint pixels on the screen, and what assistive technologies (like screen readers) use to interpret the page for visually impaired users.

We must understand semantic HTML. Tags like `<div>` and `<span>` are meaningless. Instead, use `<header>`, `<main>`, `<article>`, `<section>`, and `<footer>`.

### The Importance of ARIA

Accessible Rich Internet Applications (ARIA) roles are HTML attributes that provide extra semantic information to assistive technologies. For example, if you build a custom toggle switch out of a `<div>`, a screen reader won't know it's a switch. You must add `role="switch"` and `aria-checked="true"`.

### Milestone Project: Semantic Portfolio
**Objective:** Build a personal portfolio strictly using HTML5 semantic tags without writing a single line of CSS.
**Requirements:**
- Use `<header>`, `<main>`, `<article>`, `<section>`, `<footer>`.
- Include an accessible form using `<label for="id">`.
- Focus on the document outline and screen reader accessibility.
