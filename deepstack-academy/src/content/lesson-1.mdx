# Lesson 1: The Modern UI & Foundation

Welcome to the foundation of web development. We will ensure you do not just memorize tags, but understand how browsers render interfaces.

## HTML5 & Accessibility (A11y)

Go beyond basic tags. We must understand semantic HTML, document object model (DOM) trees, and the critical importance of ARIA roles, screen readers, and building accessible web apps from day one.

**Resources:**
* [MDN Web Docs: HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
* [W3C Accessibility Guidelines](https://www.w3.org/WAI/standards-guidelines/wcag/)

### Milestone Project: Semantic Portfolio
Build a personal portfolio strictly using HTML5 semantic tags (`<header>`, `<main>`, `<article>`, `<section>`, `<footer>`) without writing a single line of CSS. Focus on the document outline and screen reader accessibility.
