# Lesson 6: The Database Layer (MongoDB)

Data modeling is where most intermediate developers struggle. We will go far beyond basic CRUD operations.

## Advanced Mongoose
Learn complex schema design (referencing vs. embedding), indexing for query performance, population, virtuals, middleware (pre/post hooks), and Aggregation Pipelines.

**Resources:**
* [MongoDB University](https://learn.mongodb.com/)
* [Mongoose Documentation](https://mongoosejs.com/docs/)

### Milestone Project: Data Analytics Engine
Write complex Mongoose Aggregation pipelines to generate analytical reports from a large, seeded database of user transactions.
