# Lesson 4: React & Frontend Architecture

Move away from basic tutorials and focus on how React actually works under the hood. Understand the reconciliation process and diffing algorithm.

## Hooks & State Management
Deep dive into `useState`, `useEffect` (including cleanup functions), `useContext`, and performance hooks like `useMemo` and `useCallback`.

**Resources:**
* [React Official Documentation](https://react.dev/)

### Milestone Project: Complex State Manager
Create an e-commerce shopping cart application. You must use `useReducer` and `useContext` to manage the global cart state (adding items, removing, calculating totals).
