# Lesson 2: CSS3 & Responsive Design

CSS is not just about making things look pretty; it's a declarative programming language for the browser's painting engine. Deep dive into the CSS Box Model, specificity, Flexbox, and CSS Grid.

## The Box Model & Layout Algorithms

Every element on a web page is a rectangular box. Understanding `margin`, `border`, `padding`, and `content` is non-negotiable. Furthermore, understand how `box-sizing: border-box` changes this calculation to make layout math easier.

We will master CSS Grid for two-dimensional layouts (overall page structure) and Flexbox for one-dimensional layouts (aligning items in a row or column).

## Tailwind CSS: Utility-First Architecture

We transition from raw CSS to utility-first styling with Tailwind CSS. Instead of inventing class names like `.card-container`, you compose styles using utilities like `flex p-4 bg-white shadow-lg rounded-xl`.

Learn how to configure the `tailwind.config.js` file to create custom design systems, use arbitrary values (e.g., `h-[500px]`), and optimize for production by purging unused styles.

**Resources:**
