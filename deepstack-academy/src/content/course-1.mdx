## HTML5 & Accessibility (A11y)

### Semantic HTML & The DOM Tree

When a browser receives HTML, it constructs the **Document Object Model (DOM)** tree. Using semantic tags (`<header>`, `<main>`, `<article>`, `<footer>`) isn't just about clean code—it's about telling the browser and assistive technologies what the content *means*.

```html
<!-- Bad Practice (Div Soup) -->
<div class="header">
  <div class="nav">...</div>
</div>

<!-- Good Practice -->
<header>
  <nav aria-label="Main Navigation">...</nav>
</header>
```

### ARIA & Accessibility from Day One
Accessibility is not an afterthought. You must consider ARIA roles, contrast ratios, and keyboard navigation.

## CSS3 & Responsive Design

### The CSS Box Model

Every element in CSS is a box. Understanding `margin`, `border`, `padding`, and `content` is essential to mastering layouts.
